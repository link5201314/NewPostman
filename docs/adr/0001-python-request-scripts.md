# Before/After Script 使用 Python 並視為受信任程式碼

- **狀態：** 已接受

第一版的 Before request 與 After request Script 使用 Python，並透過明確的腳本上下文介面提供請求、回應及執行期變數。腳本視為使用者明確信任的程式碼，可使用一般 Python 能力，包括讀寫本機檔案；執行前必須清楚警告使用者，且不得宣稱此設計提供安全隔離。

此選擇沿用應用程式的主要語言，避免第一版同時維護第二種腳本執行環境。相對地，執行腳本可能造成任意本機副作用，因此信任邊界必須明確。若未來需要執行不受信任的腳本，或需要相容 Postman 的 JavaScript，必須另外設計並評估具體隔離機制或 JavaScript 執行環境；一般 Python 執行環境不構成沙箱。
